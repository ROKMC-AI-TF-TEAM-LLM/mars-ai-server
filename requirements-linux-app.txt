# L40 운영 — venv-app (MARS 앱 + 임베딩 8001 + 리랭커 8002)

# venv-llm과 분리한다 (사유는 requirements-linux-llm.txt 참조).
# transformers는 여기서 고정하지 않는다 — FlagEmbedding이 4.44.2를 끌고 온다.
#
# ⚠️ setuptools·wheel은 **목록에 있어야 하고, 설치는 먼저 따로 해야 한다.**
#
#   pip install --no-index --find-links wheels/ --upgrade setuptools wheel   ← 먼저
#   pip install --no-index --find-links wheels/ -r requirements-linux-app.txt
#
# 목록에 두는 이유: pip freeze가 셋(setuptools·pip·wheel)을 기본 제외하는데,
# FlagEmbedding은 wheel이 없어 sdist로 빌드되므로 둘 다 반입해야 한다.
# pip download가 이 목록을 보고 받으므로 여기서 빼면 안 된다 (troubleshooting ③).
#
# 먼저 까는 이유 (실측): 이 파일로 한꺼번에 깔면 ① 반입한 setuptools가 아니라
# venv 기본값이 남고(이미 있으면 업그레이드 안 함) ② wheel이 아직 없는 시점에
# kiwipiepy_model이 빌드돼 legacy setup.py 경로를 탄다.
#
# ⚠️ 설치할 때 --no-binary를 주지 않는다. 그건 다운로드 전용 플래그다
# (FlagEmbedding sdist를 받기 위해). 설치에도 주면 legacy 경로를 탄다.
#
# 버전 상한은 두지 않는다. 예전엔 pymilvus 2.5.4가 pkg_resources를 요구해
# setuptools<81로 묶었으나 pymilvus 3.x는 쓰지 않는다.
setuptools
wheel
